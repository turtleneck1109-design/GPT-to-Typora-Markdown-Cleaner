**合取**和**析取**是逻辑运算里的两个基本概念。

## 1. 合取：并且 / AND

合取表示“两个条件都成立，整体才成立”。

符号常写作：

(A \land B)

读作：

A 并且 B

例子：

命题 A：今天下雨
命题 B：我带伞了

(A \land B)：今天下雨，并且我带伞了。

只有当 **A 真、B 也真** 时，(A \land B) 才是真。

| A    | B    | (A \land B) |
| ---- | ---- | ----------- |
| 真   | 真   | 真          |
| 真   | 假   | 假          |
| 假   | 真   | 假          |
| 假   | 假   | 假          |

## 2. 析取：或者 / OR

析取表示“至少有一个条件成立，整体就成立”。

符号常写作：

(A \lor B)

读作：

A 或者 B

例子：

命题 A：今天下雨
命题 B：今天刮风

(A \lor B)：今天下雨，或者今天刮风。

只要 **A 和 B 中至少一个为真**，(A \lor B) 就是真。

| A    | B    | (A \lor B) |
| ---- | ---- | ---------- |
| 真   | 真   | 真         |
| 真   | 假   | 真         |
| 假   | 真   | 真         |
| 假   | 假   | 假         |

## 记忆方法

合取 = 合在一起都要满足 = 并且 = AND = ( \land )

析取 = 分开选择满足一个即可 = 或者 = OR = ( \lor )
